# Black-Rock-Stock-Price-Prediction-using-Historical-Data-of-Past-10-Years
Quantitative forecasting of BlackRock (BLK) stock using 10 years of market data in R. Evaluates multiple time series models (ARIMA, Holt-Winters, Moving Average) to predict future price trajectories. Includes stationarity testing (KPSS), data transformation, and model optimization using MAPE as the primary error metric.
